🧭 OJT 사고예방·비상대응 확인 가이드

공동훈련센터가 학습기업 방문 시 확인·안내할 핵심 사항만 정리했습니다.

센터 역할 원칙 · 공동훈련센터는 사업장의 안전관리 상태를 대신 판정하지 않습니다. 학습기업이 법정의무를 이행하고 있는지 확인하고, 미흡하거나 불명확한 사항은 사업주·안전보건 담당자 또는 전문기관에 확인하도록 안내합니다.
현장 방문 시 우선 확인할 핵심 3개 항목입니다. 업종·작업내용·위험요인에 따라 추가 확인이 필요합니다.
근거·정리 기준 · 일학습병행법 제16조·제25조, 산업안전보건법 제29조·제36조의 핵심 의무를 공동훈련센터의 현장지원 관점에서 3개 항목으로 묶었습니다. 법령이 정한 고정 체크리스트는 아닙니다.
A-1 · 법정 안전보건교육 이행 여부 확인

학습기업은 학습근로자의 실제 업무와 작업환경에 맞는 정기교육·채용 시 교육·작업내용 변경 시 교육·특별교육 해당 여부를 확인하고 사업주 책임으로 실시합니다. 공동훈련센터는 실시 여부와 증빙 유무를 확인하고 필요한 자료를 안내합니다.

★ 확인 : 교육 종류·시간·내용·방법 · 실제 위험요인 반영 · 실시 기록
▲ 일학습병행법 제25조제6항 · 산업안전보건법 제29조
A-2 · 작업 전 안전관리 확인

센터가 위험성평가를 대신하지 않고, 사업장의 위험성평가와 작업절차가 OJT에 반영되는지 확인합니다.

★ 확인 : 방호장치 · 전원 차단/잠금·표지 · 보호구 · 작업자 자격·숙련도 · 작업지휘자/감시인 필요 여부 · 비상연락망
▲ 산업안전보건법 제36조 및 작업별 산업안전보건기준에 관한 규칙 적용 여부는 사업장에서 확인
A-3 · OJT 지도체계 확인

OJT는 인정된 훈련과정과 사업장 작업절차에 따라 기업현장교사의 지도 아래 실시합니다. 자격·작업지휘자·감시인 등이 필요한 작업은 해당 요건을 충족한 경우에만 수행합니다.

★ 확인 : 기업현장교사 지정 · 승인된 작업방법 준수 · 임의조작 금지 · 이상징후 시 작업중지·보고 · 비상대응 방법 숙지
▲ 일학습병행법 제25조제2항 · 급박한 위험 시 산업안전보건법 제51조·제52조
B-1 · 사고 발생 즉시
작업중지·대피급박한 위험이 있거나 사고가 발생하면 추가 피해가 없도록 작업을 멈추고 안전한 장소로 대피합니다.
응급조치·119부상자 상태를 확인하고 긴급한 경우 119에 신고합니다. 구조자는 자신의 안전을 확보한 범위에서 응급처치를 합니다.
현장책임자 연락기업현장교사·관리감독자·안전보건 담당자 등 사업장 책임자에게 즉시 알립니다. 인명구조·응급조치 및 2차 사고 방지에 지장이 없는 범위에서 현장을 보존합니다.
B-2 · 보고 경로는 반드시 분리
중요 · 일학습병행 내부보고와 「산업안전보건법」상 법정 산업재해 보고는 서로 다른 절차입니다. 공동훈련센터에 보고했다고 법정 신고가 완료되는 것은 아닙니다.

OJT 산업안전 실무자료 사용법

SWLC-SAFETY-2026-01 · 배포기준 2026. 8. 12.

목적 · 공동훈련센터가 학습기업 방문 시 사고예방 확인, 비상대응 안내, 일학습병행 내부보고와 법정 산업재해 보고의 구분, 공식 사고보고서 작성까지 한 화면에서 빠르게 확인하도록 만든 실무 보조자료입니다.

1. 센터정보 입력2. 필요 시 로고 설정3. 조문 확인4. 예방사항 안내5. 사고 시 Quick Action6. 공식서식 작성

1. 방문 전 기본 설정

  1. 공동훈련센터 기본정보에 센터명·담당자·연락처를 입력합니다.
  2. 필요한 경우 공동훈련센터 로고를 선택합니다. 로고 파일은 브라우저 저장소에 저장하지 않습니다.
  3. 센터 기본정보는 현재 탭의 세션 동안만 임시 유지되며, 탭·창을 닫으면 초기화됩니다.

2. 안전보건 관련 조문 확인

  1. ↗ 조문 확인을 눌러 국가법령정보센터의 해당 조문을 직접 확인합니다.
  2. 조문 링크를 열면 해당 항목이 ✓ 확인 완료로 표시되어 현장 확인 여부를 구분할 수 있습니다.
  3. 확인 표시는 사용 편의를 위한 기능이며 법정교육·안전진단 이수 또는 법적 적합성 판정을 의미하지 않습니다.

3. 평상시 사고예방 컨설팅

  1. PART 1의 사고예방 영상을 필요에 따라 시청하거나 학습근로자에게 공유합니다.
  2. PART 2의 A. 안전사고 예방 절차를 펼쳐 법정교육 이행 여부, 작업 전 안전관리, OJT 지도체계를 확인·안내합니다.
  3. 센터는 사업장의 위험성평가나 안전진단을 대신하지 않고, 확인·안내·전문기관 연계 역할에 집중합니다.

4. 사고 발생 시 우선 사용

  1. 📞 사고발생 Quick Action은 처음부터 펼쳐져 있습니다. 작업중지·대피 → 응급조치·119 → 현장책임자 연락 순서를 우선 확인합니다.
  2. B. 비상 대응 절차를 펼쳐 현장 응급대응, 일학습병행 내부보고, 법정 산업재해 보고를 서로 구분해 안내합니다.
  3. 공동훈련센터 내부보고와 사업주의 지방고용노동관서 법정보고는 서로 대체되지 않습니다.

5. 사고보고서 작성

  1. 상단의 HWP 다운로드는 2026년 한국산업인력공단 시행 공문 첨부 공식서식입니다.
  2. 화면의 안전사고 보고서 작성 보조에 내용을 입력한 후 PDF로 출력할 수 있습니다.
  3. 사고자 성명·생년월일·연락처·사고내용 등은 브라우저 저장소에 자동 저장하지 않습니다.
공용·공동 PC에서는 작성·출력 후 탭/창을 닫고, 생성된 파일과 출력물은 기관의 개인정보·기록물 관리기준에 따라 관리합니다.

6. 활용 시 유의사항

  • 본 자료는 공동훈련센터의 OJT 현장지원용 실무 보조도구입니다.
  • 법률자문, 공식 안전진단, 위험성평가, 법정 안전보건교육 또는 법정 신고를 대신하지 않습니다.
  • 업종·작업내용·위험요인·사고유형에 따라 최신 법령과 관할 공단·지방고용노동관서 안내를 우선 확인합니다.
핵심 · 사고 발생 시에는 자료 작성보다 인명 보호와 2차 사고 방지가 우선입니다. 현장 조치 후 내부보고와 법정 보고의 해당 여부를 각각 확인해 주세요.
